# Digital Maintenance Complaint Lifecycle Management System

## Project Overview
The Digital Maintenance Complaint Lifecycle Management System is a full-stack application designed to improve how maintenance issues are reported, tracked, and resolved.

It eliminates manual reporting (emails/messages) by providing a centralized system where users can submit complaints, and staff can manage and resolve them efficiently with full tracking and accountability.

## Roles
- Complainant (User / Student / Staff) – Reports maintenance issues
- Supervisor – Assigns and monitors tasks
- Maintenance Staff – Fixes reported issues and updates status
- System Admin – Manages system data and users

## Tech Stack
- Flutter (Mobile App)
- ASP.NET (Web App)
- Supabase (Database)

## Features
- Submit maintenance complaints
- Track complaint status (Pending, In Progress, Completed)
- Assign staff to issues
- Upload proof and comments
- View complaint history

## Project Goal
To improve communication and efficiency in handling maintenance issues.
